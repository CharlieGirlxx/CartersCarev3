# Carter's Care Platform - Staff Onboarding Guide

## Quick Start (5 Minutes)

### For Support Workers
1. **Login:** Use your email and password
2. **Dashboard:** See today's shifts and assigned clients
3. **Assign Yourself to Shift:** Click "Clock In" button (floating action button on mobile)
4. **View Client Info:** Click client name to see allergies, emergency contacts, medications
5. **Add Note:** Click "Add Note" tab, describe what you did, click Save
6. **Report Issue:** Click "Report Incident" floating button if something unusual happens

### For Rostering Coordinators
1. **Login:** Navigate to Clients section
2. **Open Client:** Click client name
3. **Go to Shifts Tab:** See week/month view
4. **Add Shift:** Click "Add Shift" button, select date/time/worker
5. **Drag Worker:** Assign support worker by dragging their name onto shift
6. **Publish Schedule:** Click "Publish" to send notifications

### For Managers
1. **Dashboard:** Overview of all active shifts, incidents, expiring documents
2. **Compliance Tab:** See staff compliance status, expiring certifications
3. **Reports:** Generate incident trends, staff compliance, shift completion
4. **Settings:** Configure organization details, user roles, notification preferences

## Role-Based Access Explained

### Support Worker
**Access Level:** Can see only assigned clients and shifts
**Actions Allowed:**
- View assigned client details
- Clock in/out of shifts
- Add shift notes
- Report incidents
- Upload supporting documents
- View own schedule
- Cannot:** Access other workers' data, change rosters, access settings

**Mobile Optimized:** Yes - all core functions accessible via mobile

### Rostering Coordinator
**Access Level:** Can see all clients, create and manage shifts
**Actions Allowed:**
- View all clients and their profiles
- Create and modify shifts
- Assign workers to shifts
- Prevent double-bookings (system enforces)
- View team rosters
- Add notes to shifts
- Cannot:** Delete workers, access financial, modify user accounts

**Key Feature:** Drag-and-drop shift assignment

### Team Leader / Supervisor
**Access Level:** Can manage team, review incidents, approve documents
**Actions Allowed:**
- Supervise team roster
- Review incident reports
- Approve incident resolutions
- Verify worker compliance
- Generate team reports
- Monitor shift completion
- Cannot:** Access financial, modify system settings, delete data

### Admin / System Administrator
**Access Level:** Full system access
**Actions Allowed:**
- User account management
- System settings and configuration
- Data exports and reports
- Compliance and audit trail review
- Backup and recovery
- Security settings (MFA, passwords)
- Cannot:** No restrictions (but all actions logged and auditable)

## Common Tasks & How-Tos

### Task 1: Clock In for Shift
**For Support Workers on Mobile:**
1. Open app
2. Tap floating "Clock In" button (bottom right)
3. Confirm location/time
4. Tap "Clock In"
5. You'll see "On Shift" indicator

**On Desktop:**
1. Go to Rosters → Today's Shifts
2. Find your shift
3. Click "Clock In" button
4. Confirm details
5. Status updates to "In Progress"

### Task 2: Record Client Care Note
**Process:**
1. Open Client profile
2. Go to "Notes" tab
3. Click "Add Note" button
4. Select note type (personal care, medication admin, behavior, progress, other)
5. Write what you did (form is mobile-friendly, can use voice dictation)
6. Add any files/photos
7. Click "Save"
8. Note appears in client's timeline with timestamp and your name

**Note:** All notes are timestamped and logged for compliance.

### Task 3: Report an Incident
**Process:**
1. Click floating "Report Incident" button (or go to Incidents → New)
2. Select incident type (injury, behavior, safeguarding concern, medication error, near miss, other)
3. Select client involved
4. Describe what happened
5. Rate severity (low/medium/high)
6. Attach photos/evidence if available
7. Submit

**What Happens Next:**
- Supervisor gets notified immediately
- Incident appears in Compliance dashboard
- Compliance team may follow up
- Resolution is tracked and logged

### Task 4: View Client Medical Alerts
**Process:**
1. Open Client profile
2. Look for "Alerts" section (red banner at top if there are active alerts)
3. See: Allergies, Medications, Restrictions, Emergency Contacts
4. All info is from latest Care Plan

**Emergency Protocol:** If client has unknown allergic reaction, call 000 first, then notify supervisor.

### Task 5: Create a New Shift
**For Rostering Coordinators:**
1. Go to Rosters → Calendar view
2. Click on date/time slot
3. Fill in: Client, Start Time, End Time, Type (personal care/support/community)
4. Set if two workers required
5. Add special notes
6. Click "Save as Draft" to save without publishing
7. Click "Publish" to send notifications to available workers

**For Mobile:**
1. Go to client profile
2. Shifts tab → "Add Shift" button
3. Same process above

### Task 6: Assign Worker to Shift
**Desktop (Recommended):**
1. Go to Rosters → Week view
2. Locate the shift
3. Drag worker name from available list onto shift
4. System checks for conflicts (won't allow double-booking)
5. Worker gets notification

**Mobile:**
1. Go to shift
2. Tap "Assign Worker"
3. Select from available workers
4. Tap "Confirm"

### Task 7: Upload Document for Client
**For Documents Like:** Support Plans, Service Agreements, Medical Records, Behavior Plans
**Process:**
1. Open Client → Documents tab
2. Click "Upload Document"
3. Select document type
4. Upload file (PDF, Word, images supported)
5. Add expiry date if applicable
6. Add version number if replacing old version
7. Click "Save"

**Document Management:** System tracks versions, alerts on expiry, archives old versions

### Task 8: Generate Compliance Report
**For Managers:**
1. Go to Compliance → Reports
2. Select report type: Staff Compliance, Document Expiry, Incidents, Shift Completion
3. Select date range
4. Choose format: PDF or CSV
5. Click "Generate"
6. Download or email report

**Reports Available:**
- Staff certifications expiring soon
- Documents expiring this month
- Incident trends by type
- Shift completion rates
- Worker compliance status

### Task 9: Reset Password
**For Any User:**
1. Go to login page
2. Click "Forgot Password?"
3. Enter email address
4. Check email (takes ~2 minutes)
5. Click link in email
6. Enter new password
7. Log in with new password

**Admin Override:** Admins can reset passwords for users from Settings → Users

### Task 10: Request Time Off / Leave
**Feature Coming in Phase 2 Update**
Currently: Contact your rostering coordinator directly

## Important Policies & Guidelines

### Data Privacy
- Never share client information outside the app
- Don't leave browser/device unattended while logged in
- Log out at end of shift
- Don't take photos of confidential documents
- All data access is logged for compliance

### Safety & Compliance
- Always verify client identity before providing care
- Follow client's support plan exactly
- Document all care provided (required for compliance)
- Report all incidents, even minor ones
- Never deviate from medication instructions

### Incident Reporting Protocol
1. **Immediate:** If client safety at risk, call 000
2. **Report in App:** Within 24 hours maximum
3. **Severity Indicators:**
   - **High:** Injury, safeguarding concern, medical event
   - **Medium:** Behavioral issue, medication concern, compliance gap
   - **Low:** Minor incident, documentation note
4. **Follow-up:** Supervisor will contact if needed

### Shift Requirements
- Arrive 10 minutes early
- Log in/clock in via app
- Follow client plan exactly
- Log all activities in notes
- Clock out when finished
- Report any issues immediately

## Troubleshooting

### "I can't log in"
1. Check email and password are correct (caps lock?)
2. Click "Forgot Password" to reset
3. If still not working, contact admin: support@carterscare.com.au

### "I can't see my client"
**Support Workers:** You only see clients assigned to you. Contact coordinator.
**Coordinators/Managers:** Check filters on Clients page - may be filtered by location/status

### "My shift doesn't appear"
1. Check date and filters
2. Wait 5 minutes for refresh
3. Try logging out and back in
4. Contact rostering coordinator

### "I can't upload a document"
1. Check file format (PDF, Word, PNG, JPG supported)
2. Check file size (max 50MB)
3. Check your internet connection
4. Try refreshing page
5. Use different browser or contact support

### "App is slow / not responding"
1. Check your internet connection
2. Close other browser tabs
3. Clear browser cache (Settings → Privacy)
4. Try again
5. If still slow, contact IT support

### "I accidentally deleted something"
**Data is protected:** Nothing is permanently deleted. Contact your manager/admin to restore.

## Tips & Best Practices

### For Mobile Use
- Use mobile app on phone for best experience
- Portrait orientation works best
- Use "Quick Actions" floating buttons for fast access
- Don't use public WiFi for sensitive data
- Keep app updated in app store

### For Efficient Rostering
- Use week view for overview
- Use month view for planning ahead
- Use drag-and-drop on desktop (faster than mobile)
- Set up recurring shifts (saves time)
- Use notes to communicate special requirements

### For Complete Notes
- Write specific details (client mood, what you did, outcomes)
- Use relevant categories/tags
- Include time for admin tasks (breaks, handover, etc.)
- Add photos of wound care, behavioral incidents, etc.
- Mention if follow-up needed

### For Compliance
- Add notes same day (not from memory days later)
- Always include date/time
- Be honest about incidents (no penalties for reporting)
- Update documents before expiry
- Check compliance dashboard monthly

### Mobile Security
- Use strong password (12+ characters)
- Enable biometric unlock if available
- Log out after each use on shared devices
- Don't store confidential info in photos
- Use app, not browser, for security
